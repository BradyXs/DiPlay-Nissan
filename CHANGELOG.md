# Changelog

## NiPlay 0.2.62

- Nissan Android 4.4.3 / ARMv7 profile with wireless and USB CarPlay support.
- Media, navigation and call audio controls, including an optional call output stream choice.
- Steering-wheel media, call and Siri controls on supported Nissan firmware.
- Local diagnostic report export.

Earlier DiPlay development history and contributor credits are available in the [DiPlay repository](https://github.com/shihabal3amri/DiPlay). NiPlay also incorporates work from [DiPlay-Legacy-Android](https://github.com/programmerguohuajing/DiPlay-Legacy-Android). See the [third-party notices](docs/THIRD_PARTY_NOTICES.md).
