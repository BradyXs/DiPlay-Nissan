日产车机专用 · Android 4.4.3 · ARMv7

让 CarPlay 适配
你的逍客车机。

NiPlay 基于 DiPlay 和 DiPlay-Legacy-Android，主要面向 2019 款日产逍客的 Android 4.4.3 车机。

下载日产车机 APK 阅读构建指南
01

连接

支持无线和 USB CarPlay，按日产车机的连接方式定制。

02

播放

提供车机上的视频与音频播放，以及媒体、导航和通话音量控制。

03

操作

支持已适配固件上的方向盘媒体按键，并可导出诊断日志。

关于公开版本

Release 提供日产 Android 4.4.3 / ARMv7 安装包、校验值、版本说明和源码归档。APK 内含运行所需认证文件，公开下载后可被提取；源码仓库不包含认证文件或 Android 签名私钥。其他车机的兼容性尚未验证。
